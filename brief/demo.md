# Stage 2 live demo

1. Open the locally served dashboard. Point to the trained-model badge and
   the synthetic input label. Describe the three-day input and daily forecast
   before clicking **Run both timelines**.
2. Select **Warm Bay of Bengal** and view precipitation. Move from day 1 to
   day 4. Explain that Prime is the reference, Branch changes only the last
   input day, and the difference map uses the same physical units.
3. Invite a judge to choose another location or shock. Run both timelines and
   compare the early and late response footprints. Use the zero-shock check
   to demonstrate a deterministic baseline.
4. Open land exposure. Compare cumulative rain or heavy-rain days, then run
   the sensitivity ensemble. Explain the min–max bands and that exceedance
   frequencies come from nine scenarios and are uncalibrated.
5. Use **Spin up start state** to generate a new model input. Show that the
   dashboard labels it as model output and can make a fresh forecast from it.
6. Close with measured limits. The held-out winter proxy missed heavy rain
   on days 4 and 8, and one of the ten Bay shocks missed the propagation
   criterion. Point to the brief and validation metrics for the exact scope.
