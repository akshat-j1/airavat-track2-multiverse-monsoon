# Live brief walkthrough

- Open the locally served dashboard and check that the trained model is ready. Click **Generate demo** with the default day of year 196, horizon of 10 days, and radius of 4.5 cells.
- Select **Heat dome**, run both timelines, set **View** to precipitation, and advance to day 4. Prime is the reference. Branch applies the +4 K bump to the last input state. In the difference map, point out the localized increase, the 0.706 mm/day absolute peak and the 37-cell footprint.
- Under **What changes on land?**, choose **Heavy-rain days** and leave the threshold at 64.5 mm/day. For a drain inspection discussion, point to the flagged cells. Of 736 land cells, 5 reached the threshold in each timeline. The affected days were 3, 4 and 5 in both. The visible rain difference did not produce an additional threshold crossing.
- If asked about uncertainty, show **Run sensitivity ensemble** and explain that the exceedance frequencies are uncalibrated. If asked about skill, use the brief's held-out table and scope box. The hidden organizer cases are unverified.
